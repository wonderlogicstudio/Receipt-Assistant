# 파일럿 인터뷰 질문지

## 사용 원칙

- 유도 질문을 피한다.
- “좋다/나쁘다”보다 실제 행동과 불편한 지점을 묻는다.
- 비용항목 추천은 참고용으로 이해했는지 확인한다.
- 실제 파일명, 카드번호, 주민번호, 전화번호, 민감정보는 기록하지 않는다.

## 공통 질문

1. 현재 영수증과 증빙 자료를 어떻게 정리하고 있나요?
2. 한 달에 대략 몇 건 정도 처리하나요?
3. 정리 과정에서 가장 시간이 오래 걸리는 단계는 무엇인가요?
4. 자료를 최종적으로 어떤 형식으로 전달하거나 보관하나요?
5. 이번 엑셀 결과물은 이해하기 쉬웠나요?
6. 검토필요 표시가 확인 작업에 도움이 되었나요?
7. 비용항목 추천은 참고용으로 유용했나요?
8. 검수 테이블에서 수정하기 어려운 항목이 있었나요?
9. 다운로드한 엑셀에서 꼭 추가되었으면 하는 컬럼이 있나요?
10. 어떤 부분이 가장 불편했나요?

## 세무사/세무사 사무실 질문

1. 고객이 보내는 자료 중 가장 다루기 불편한 형태는 무엇인가요?
2. 세무사 전달용 엑셀에 꼭 필요한 컬럼은 무엇인가요?
3. 검토필요 또는 미확인 사유는 어떤 방식으로 표시되면 좋나요?
4. 원본 파일명 추적이 업무에 필요한가요?
5. 카드 사용내역 대조 결과는 어느 수준이면 충분한가요?
6. 비용항목 추천값은 어떤 방식으로 표시되어야 참고하기 쉬운가요?
7. 사무실에서 유료로 사용하려면 어떤 조건이 필요할까요?
8. 직원이 반복적으로 쓰기 위해 필요한 기능은 무엇인가요?

## 1인 사업자/프리랜서 질문

1. 월말 증빙 정리에 보통 얼마나 시간이 걸리나요?
2. 세무사에게 자료를 어떤 방식으로 넘기나요?
3. 영수증과 카드내역을 따로 모으는 과정에서 가장 번거로운 점은 무엇인가요?
4. 자동으로 정리된 결과를 어느 정도까지 신뢰할 수 있나요?
5. 어떤 항목은 반드시 직접 확인하고 싶나요?
6. 1회 사용이라면 얼마 정도가 부담 없나요?
7. 월 구독이라면 어떤 조건이 있어야 사용할 것 같나요?

## 소상공인/쇼핑몰 운영자 질문

1. 카드내역, 영수증, 매출 관련 자료가 얼마나 흩어져 있나요?
2. 자료 정리는 직접 하나요, 직원이 하나요?
3. 월별요약이 실제 업무에 필요한가요?
4. 비용항목별요약이 실제 업무에 필요한가요?
5. 엑셀 다운로드 결과물이 지금 업무 방식에 맞나요?
6. 업로드해야 하는 파일 종류가 더 있나요?
7. 반복 사용한다면 가장 줄이고 싶은 작업은 무엇인가요?

## 가격/구매 의향 질문

부담스럽지 않게 선택지로 묻는다.

| 유형 | 질문 |
|---|---|
| 1회 정리 대행 | 한 번 정리해주는 방식이라면 어느 가격대가 적절한가요? |
| 월 구독 | 매월 사용할 수 있다면 어느 가격대가 적절한가요? |
| 세무사 사무실용 | 사무실 여러 명이 쓴다면 어떤 과금 방식이 좋나요? |
| 맞춤 구축형 | 사무실 양식에 맞춘 구축형이 필요할까요? |

선택지 예시:

- 사용 의향 없음
- 1만원 미만
- 1만~3만원
- 3만~5만원
- 5만원 이상
- 사용량에 따라 다름

## 개선 요청 질문

1. 가장 먼저 고쳐야 할 부분은 무엇인가요?
2. 없어도 되는 항목은 무엇인가요?
3. 추가되면 바로 다시 써볼 기능은 무엇인가요?
4. 엑셀 결과물에서 헷갈린 컬럼은 무엇인가요?
5. 검토필요 사유 중 이해하기 어려운 표현이 있었나요?
6. 다음 파일럿에서 어떤 샘플로 다시 테스트하면 좋을까요?
