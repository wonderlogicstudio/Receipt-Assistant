# 표준 엑셀 정리 파일 구조

이 문서는 MVP가 생성하는 엑셀 파일의 시트 의미와 주요 컬럼을 설명한다. 엑셀은 세무사 전달용 정리 자료로 사용하기 위한 출력물이며, 사용자가 검수한 값을 기준으로 한다.

## 파일명

```text
receipt_summary_YYYYMMDD_HHMMSS.xlsx
```

## 시트 구성

| 순서 | 시트 의미 | 목적 |
|---|---|---|
| 01 | 정리내역 | 검수 후 포함 대상으로 남은 영수증 목록 |
| 02 | 월별요약 | 월별 건수와 금액 요약 |
| 03 | 비용항목별요약 | 최종 비용항목 기준 요약 |
| 04 | 검토필요 | 검토필요 사유, 경고, 카드 매칭 후보, 중복 의심 건 |
| 05 | 카드대조 | 영수증과 카드 사용내역의 규칙 기반 대조 결과 |
| 06 | 원본파일목록 | 업로드 원본 파일명 기준 처리 요약 |
| 07 | 처리로그 | 처리 단계, 상태, 짧은 메시지 |
| 08 | 제외내역 | 검수 화면에서 제외한 영수증 목록 |

## 정리내역 주요 컬럼

```text
No
사용일자
상호
사업자번호
총금액
할인전금액
할인금액
최종결제금액
실제결제금액
금액판단기준
금액검토사유
공급가액
부가세
추정공급가액
추정부가세
부가세출처
부가세검토사유
민감문구감지
민감문구유형
결제수단
시스템 추천 비용항목
최종 비용항목
검수상태
검토사유
카드매칭상태
카드매칭사유
중복의심여부
원본파일명
비고
```

`시스템 추천 비용항목`은 참고용 추천값이다. `최종 비용항목`은 사용자가 검수 화면에서 확인하거나 수정한 값이다.

`총금액`은 비용 기준 최종 결제금액이다. 할인금액이 있는 영수증은 할인 전 금액과 할인/쿠폰/포인트 등 차감 금액, 할인 적용 후 결제대상금액, 실제 결제금액을 별도 컬럼으로 표시한다. 할인 후 결제금액이 0원인 건은 자동 제외하지 않고 검토필요 사유로 확인할 수 있다.

`최종결제금액`은 영수증에 표시된 합계금액 또는 결제대상금액 기준이다. `실제결제금액`은 받은금액, 카드결제, 현금결제 등 실제 결제수단 기준이다. 설명용 문구나 푸터 숫자가 실제결제금액으로 의심되는 경우에는 `금액검토사유`로 남기고 `총금액`은 더 신뢰할 수 있는 최종/결제대상금액 기준으로 표시할 수 있다.

`공급가액`과 `부가세`는 영수증에 명시된 값만 표시한다. 부가세가 명시되지 않은 경우 `추정공급가액`과 `추정부가세`에 참고용 역산값을 표시하며, `부가세출처`와 `부가세검토사유`로 명시값과 구분한다. 추정값은 사용자 확인이 필요한 참고값이다.

`민감문구감지`와 `민감문구유형`은 OCR 결과에서 WiFi PW, 비밀번호, 카드번호 전체 등 민감문구 가능성이 감지된 경우 category만 표시한다. 실제 민감값은 엑셀에 표시하지 않는다.

## 월별요약 주요 컬럼

```text
월
건수
총금액합계
공급가액합계
부가세합계
검토필요건수
카드미매칭건수
```

공급가액합계와 부가세합계는 명시값 기준이다. 추정공급가액과 추정부가세는 정리내역에서 참고값으로 확인하며, 명시값 합계에 자동 합산하지 않는다.

## 비용항목별요약 주요 컬럼

```text
비용항목
건수
총금액합계
공급가액합계
부가세합계
검토필요건수
```

요약 기준은 최종 비용항목이다. 값이 비어 있으면 미확인 항목으로 집계될 수 있다.

## 검토필요 주요 컬럼

```text
No
사용일자
상호
총금액
검수상태
검토사유
경고
카드매칭상태
카드매칭사유
중복의심여부
원본파일명
```

할인 후 0원 결제, 참고 부가세 추정, 민감문구 감지, 금액 후보 불일치, 수량/승인번호/푸터 숫자 오인 가능성이 있는 건은 검토필요 시트에 포함될 수 있다. 이 시트에도 OCR 원문 전체와 실제 민감값은 표시하지 않는다.

```text
No
영수증사용일자
영수증상호
영수증금액
카드사용일자
카드가맹점명
카드금액
카드명
승인번호
매칭상태
매칭점수
매칭사유
후보건수
원본파일명
```

카드번호 전체와 카드 사용내역 원문 전체는 표시하지 않는다.

## 원본파일목록 주요 컬럼

```text
No
원본파일명
파일유형
처리유형
처리상태
건수
경고
내부추적ID
```

전체 로컬 절대경로와 저장 상대경로는 표시하지 않는다.

## 처리로그 주요 컬럼

```text
No
단계
상태
메시지
관련파일명
생성시각
```

OCR 원문 전체와 raw JSON 전체는 표시하지 않는다. 필요한 경우 비민감 상태 메시지만 남긴다.

## 제외내역 주요 컬럼

```text
No
사용일자
상호
총금액
제외사유
원본파일명
비고
```

제외 건은 삭제하지 않고 별도 시트에 기록한다.

## 보안 기준

- 전체 로컬 절대경로를 엑셀에 넣지 않는다.
- OCR raw text 전체를 엑셀에 넣지 않는다.
- provider raw JSON 전체를 엑셀에 넣지 않는다.
- 카드 사용내역 원문 전체를 엑셀에 넣지 않는다.
- 파일명은 경로를 제거한 이름만 표시한다.
- 부가세 참고 추정값은 명시 부가세와 구분해 표시한다.
- 민감문구 감지 시 실제 값이 아니라 category만 표시한다.
