# 표준 엑셀 산출물 구조

이 문서는 영수증 OCR 엑셀 비서 MVP가 생성하는 표준 엑셀 정리 파일의 시트와 주요 컬럼을 설명한다. 산출물은 세무사 전달용 정리와 사용자 검수 기록을 돕기 위한 파일이다.

## 시트 목록

| 시트명 | 목적 |
|---|---|
| 01_정리내역 | 검수 후 포함 대상으로 남은 영수증 목록 |
| 02_월별요약 | 사용일자 기준 월별 합계 |
| 03_비용항목별요약 | 사용자가 입력한 최종 비용항목 기준 합계 |
| 04_검토필요 | 검수 필요 사유, 경고, 카드대조 후보, 중복의심 건 |
| 05_카드대조 | 영수증과 카드 사용내역의 규칙 기반 대조 결과 |
| 06_원본파일목록 | 업로드 원본 파일명 기준 처리 요약 |
| 07_처리로그 | 처리 단계, 상태, 짧은 메시지 |
| 08_제외내역 | 검수 화면에서 제외한 영수증 목록 |

## 01_정리내역

주요 컬럼:

```text
No
사용일자
상호
사업자번호
총금액
공급가액
부가세
결제수단
시스템추천비용항목
최종비용항목
검수상태
검토사유
카드매칭상태
카드매칭사유
중복의심여부
원본파일명
비고
```

`시스템추천비용항목`은 비용항목 추천값이며, `최종비용항목`은 사용자가 검수 후 입력한 값이다. 제외 상태의 건은 이 시트에 표시하지 않는다.

## 02_월별요약

주요 컬럼:

```text
월
건수
총금액합계
공급가액합계
부가세합계
검토필요건수
카드미매칭건수
```

제외 상태가 아닌 건만 집계한다. 사용일자가 없는 건은 `날짜미확인` 그룹으로 분리한다.

## 03_비용항목별요약

주요 컬럼:

```text
비용항목
건수
총금액합계
공급가액합계
부가세합계
검토필요건수
```

집계 기준은 `최종비용항목`이다. 최종 비용항목이 비어 있으면 `미확정`으로 집계한다.

## 04_검토필요

주요 컬럼:

```text
No
사용일자
상호
총금액
검수상태
검토사유
경고
카드매칭상태
카드매칭사유
중복의심여부
원본파일명
```

검수 필요 상태, 검토사유, 경고, 카드대조 후보 또는 미매칭, 중복의심 건을 표시한다.

## 05_카드대조

주요 컬럼:

```text
No
영수증사용일자
영수증상호
영수증금액
카드사용일자
카드가맹점명
카드금액
카드명
승인번호
매칭상태
매칭점수
매칭사유
후보건수
원본파일명
```

카드번호 전체나 카드 사용내역 원문 전체는 표시하지 않는다.

## 06_원본파일목록

주요 컬럼:

```text
No
원본파일명
파일유형
처리유형
처리상태
건수
경고
내부추적ID
```

전체 로컬 경로와 저장 상대 경로는 표시하지 않는다.

## 07_처리로그

주요 컬럼:

```text
No
단계
상태
메시지
관련파일명
생성시각
```

OCR 원문 전체와 raw JSON 전체는 표시하지 않는다. 처리 상태와 짧은 메시지만 기록한다.

## 08_제외내역

주요 컬럼:

```text
No
사용일자
상호
총금액
제외사유
원본파일명
비고
```

제외 건은 삭제하지 않고 이 시트에 따로 남긴다.
