# MVP 파일럿 가이드

## 파일럿 목적

영수증 OCR 엑셀 비서 MVP가 실제 업무 흐름에서 세무사 전달용 표준 엑셀 정리 파일을 만드는 데 도움이 되는지 확인한다.

파일럿은 기능 확장이 아니라 다음을 검증한다.

- 업로드부터 엑셀 다운로드까지 흐름이 막히지 않는가
- 검수 테이블이 이해하기 쉬운가
- 검토필요 사유가 사용자의 확인 작업에 도움이 되는가
- 비용항목 추천이 참고용으로 유용한가
- 엑셀 결과물이 전달하기 쉬운 구조인가

전문가 판단 영역이나 신고 제출 가능 여부는 이번 파일럿의 검증 범위가 아니다.

## 파일럿 대상

| 대상 | 설명 |
|---|---|
| 세무사 또는 세무사 사무실 직원 | 고객이 보내는 증빙 자료를 정리하고 확인하는 사람 |
| 1인 사업자/프리랜서 | 월말 또는 분기별로 영수증과 카드내역을 정리하는 사람 |
| 소상공인/쇼핑몰 운영자 | 매장 또는 온라인 판매 관련 지출 자료를 모아 전달하는 사람 |

## 대상별 검증 포인트

| 대상 | 검증 포인트 |
|---|---|
| 세무사 또는 세무사 사무실 직원 | 엑셀 시트 구조, 필수 컬럼, 원본파일명 추적, 검토필요 사유 표시 |
| 1인 사업자/프리랜서 | 업로드 난이도, 검수 시간, 비용항목 추천의 참고 가치, 다운로드 결과 이해도 |
| 소상공인/쇼핑몰 운영자 | 카드내역과 영수증 대조, 월별요약, 비용항목별요약, 반복 사용 가능성 |

## 준비물

- 개인정보 제거 또는 더미 처리된 영수증 이미지/PDF
- 개인정보 제거 또는 더미 처리된 카드 사용내역 CSV/XLSX
- 테스트용 `.env`
- 실행 가능한 로컬 Python 환경
- `OCR_PROVIDER=mock` 기준 데모 설정
- 피드백 기록 템플릿

## 테스트 절차

1. 앱 실행: `streamlit run app/main.py`
2. `1단계: 파일 업로드`에서 영수증 이미지/PDF와 카드 사용내역 CSV/XLSX 업로드
3. `파일 저장 및 처리` 클릭
4. 처리 요약과 검수 테이블 확인
5. 일부 값 수정
6. 필요 없는 항목은 제외 상태로 변경
7. `표준 엑셀 생성` 클릭
8. `엑셀 다운로드` 클릭
9. 다운로드한 엑셀 파일 열기
10. 필수 시트와 수정값 반영 여부 확인
11. 결과물 만족도와 불편한 점 기록

## 성공 기준

### 정량 기준

| 기준 | 목표 |
|---|---|
| 업로드 → 다운로드 흐름 | 오류 없이 완료 |
| 샘플 20건 검수 | 10분 이내 완료 가능 |
| 엑셀 필수 시트 | 모두 생성 |
| 검수 수정값 | 엑셀에 반영 |
| 전체 로컬 경로 | 엑셀에 미노출 |
| OCR 원문 전체 | 엑셀에 미노출 |

### 정성 기준

| 기준 | 확인 질문 |
|---|---|
| 전달 용이성 | 세무사에게 전달하기 쉬운 구조인가 |
| 검수 용이성 | 검토필요 사유가 이해되는가 |
| 추천 유용성 | 비용항목 추천이 참고용으로 유용한가 |
| 시간 절감 | 기존 수작업 대비 시간이 줄어드는가 |
| 반복 사용성 | 다음 달에도 다시 쓸 이유가 있는가 |

## 실패/중단 기준

- 앱이 실행되지 않는다
- 파일 업로드가 되지 않는다
- `파일 저장 및 처리` 이후 결과가 표시되지 않는다
- 검수 테이블을 사용할 수 없다
- 엑셀 파일이 생성되지 않는다
- 다운로드한 엑셀 파일이 열리지 않는다
- 테스트 파일에 민감정보가 포함되어 있다

## 개인정보 주의사항

- 실제 카드번호 전체를 사용하지 않는다
- 주민번호를 사용하지 않는다
- 전화번호를 사용하지 않는다
- 민감정보가 포함된 원본 파일을 사용하지 않는다
- 실제 파일명 대신 더미 파일명을 사용한다
- 피드백 기록에는 실제 파일명, 전체 로컬 경로, 원문 내용을 적지 않는다
- 테스트 후 업로드/출력 파일은 보관 정책에 따라 정리한다

## 파일럿 결과 기록 방법

파일럿 1회마다 [pilot_feedback_template.md](pilot_feedback_template.md)를 복사해 기록한다.

기록 원칙:

- 사람 이름 대신 대상 유형만 기록
- 실제 파일명 기록 금지
- 민감정보 기록 금지
- 오류 위치는 화면 단계 기준으로 기록
- 개선 요청은 사용자의 표현을 짧게 요약
