# 샘플 사용자 흐름

이 문서는 현재 구현된 Streamlit MVP 기준의 텍스트 사용 흐름이다. 실제 화면 이미지 없이도 파일럿 진행자가 같은 순서로 테스트할 수 있도록 작성한다.

## 1단계: 앱 실행

사용자가 할 일:

```bash
streamlit run app/main.py
```

기대 결과:

- 브라우저에 `영수증 OCR 엑셀 비서 MVP` 화면이 열린다.
- 현재 OCR provider가 표시된다.

문제가 생겼을 때:

- 의존성이 설치되어 있는지 확인한다.
- `pip install -r requirements.txt`를 다시 실행한다.
- `.env`가 없어도 mock 기본값으로 실행 가능해야 한다.

## 2단계: 파일 준비

사용자가 할 일:

- 개인정보 제거 또는 더미 처리된 영수증 이미지/PDF를 준비한다.
- 개인정보 제거 또는 더미 처리된 카드 사용내역 CSV/XLSX를 준비한다.

기대 결과:

- 파일 확장자가 JPG, JPEG, PNG, PDF, XLSX, CSV 중 하나다.
- 실제 카드번호 전체, 주민번호, 전화번호, 민감정보가 포함되지 않는다.

문제가 생겼을 때:

- 원본 파일이 너무 크면 테스트용 샘플 수를 줄인다.
- 지원하지 않는 확장자는 이번 MVP에서 제외한다.

## 3단계: 파일 업로드

사용자가 할 일:

- `1단계: 파일 업로드` 영역에서 파일을 선택한다.
- 영수증 파일과 카드 사용내역 파일을 함께 업로드할 수 있다.

기대 결과:

- 업로드 파일 목록이 화면에 준비된다.
- 아직 처리 전에는 검수 테이블이 표시되지 않을 수 있다.

문제가 생겼을 때:

- 파일 확장자가 지원되는지 확인한다.
- 파일명이 너무 복잡하면 간단한 더미 파일명으로 바꾼다.

## 4단계: 처리 실행

사용자가 할 일:

- `파일 저장 및 처리` 버튼을 누른다.

기대 결과:

- 저장 메타데이터가 표시된다.
- 영수증 처리 건수와 카드내역 처리 건수가 표시된다.
- Mock OCR 기준 샘플 영수증 데이터가 생성된다.

문제가 생겼을 때:

- 카드내역 컬럼명이 인식되지 않으면 CSV/XLSX 헤더를 확인한다.
- 경고 메시지가 있으면 해당 파일 형식과 필수 컬럼을 확인한다.

## 5단계: 검수 테이블 확인

사용자가 할 일:

- `3단계: 검수` 영역의 테이블을 확인한다.
- 날짜, 상호, 금액, 결제수단, 시스템추천비용항목, 최종비용항목, 검토사유를 확인한다.

기대 결과:

- OCR/Parser 결과가 검수 대상 값으로 표시된다.
- 검토필요 건은 사유와 함께 확인할 수 있다.

문제가 생겼을 때:

- 검토필요 건이 많으면 샘플 파일 품질과 OCR provider 설정을 확인한다.
- 비용항목 추천은 참고값이므로 필요하면 직접 수정한다.

## 6단계: 오류/검토필요 건 수정

사용자가 할 일:

- 검수 테이블에서 수정할 셀을 직접 편집한다.
- 최종비용항목과 비고를 필요한 만큼 입력한다.

기대 결과:

- 수정한 값이 세션에 반영된다.
- 이후 엑셀 생성 시 수정값이 들어간다.

문제가 생겼을 때:

- 수정값이 보이지 않으면 테이블 편집 후 다른 영역을 클릭해 반영 여부를 확인한다.
- 숫자 컬럼에는 숫자만 입력한다.

## 7단계: 제외 처리

사용자가 할 일:

- 엑셀 정리내역에서 제외할 행은 검수상태를 제외로 바꾼다.

기대 결과:

- 제외 건은 `01_정리내역`에는 들어가지 않는다.
- 제외 건은 `08_제외내역`에 남는다.

문제가 생겼을 때:

- 제외 사유를 비고에 짧게 남긴다.
- 제외 상태가 의도대로 반영되는지 엑셀에서 확인한다.

## 8단계: 엑셀 생성

사용자가 할 일:

- `표준 엑셀 생성` 버튼을 누른다.

기대 결과:

- `엑셀 파일이 생성되었습니다.` 메시지가 표시된다.
- 다운로드 버튼이 표시된다.

문제가 생겼을 때:

- 오류 메시지의 단계가 엑셀 생성인지 확인한다.
- 테스트 데이터를 줄여 다시 시도한다.

## 9단계: 엑셀 다운로드

사용자가 할 일:

- `엑셀 다운로드` 버튼을 누른다.

기대 결과:

- `receipt_summary_YYYYMMDD_HHMMSS.xlsx` 형식의 파일을 받을 수 있다.

문제가 생겼을 때:

- 브라우저 다운로드 차단 여부를 확인한다.
- 파일명이 바뀌었더라도 `.xlsx` 파일인지 확인한다.

## 10단계: 엑셀 파일 확인

사용자가 할 일:

- 다운로드한 엑셀 파일을 연다.
- 필수 시트와 수정값 반영 여부를 확인한다.

기대 결과:

- `01_정리내역`
- `02_월별요약`
- `03_비용항목별요약`
- `04_검토필요`
- `05_카드대조`
- `06_원본파일목록`
- `07_처리로그`
- `08_제외내역`

문제가 생겼을 때:

- 파일이 열리지 않으면 다시 생성하고 다운로드한다.
- 원본 전체 경로나 OCR 원문 전체가 보이면 파일럿 기록에 남기고 즉시 수정 대상으로 분류한다.
